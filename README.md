# MDS211 - Machine Learning

Este repositorio contiene materiales, notebooks y recursos para el curso **MDS211: Machine Learning**.

## Estructura del repositorio

- `laboratorio_bayes_optimal.ipynb`: Notebook interactivo sobre clasificación Bayesiana y comparación con KNN, incluyendo separación de datos en entrenamiento y prueba, visualización de fronteras y evaluación de desempeño.


## Requisitos

- Python 3.12+
- Paquetes: numpy, matplotlib, scikit-learn, jupyter

Puedes instalar los paquetes necesarios ejecutando:

```
pip install -r requirements.txt
```

O bien, activar el entorno virtual incluido:

```
source env/bin/activate
```

## Ejecución de notebooks

1. Activa el entorno virtual.
2. Inicia JupyterLab o Jupyter Notebook:
   ```
   jupyter lab
   # o
   jupyter notebook
   ```
3. Abre y ejecuta los notebooks desde la interfaz web.

## Contenido principal

- **Clasificación Bayesiana:**
  - Generación de datos sintéticos
  - Entrenamiento de modelos Gaussian Mixture
  - Visualización de fronteras de decisión
  - Comparación con K-Nearest Neighbors (KNN)
  - Evaluación en conjuntos de entrenamiento y prueba

## Recursos adicionales

- Consulta el archivo PDF para teoría, ejemplos y ejercicios adicionales.
- Modifica y experimenta con los notebooks para afianzar los conceptos.
